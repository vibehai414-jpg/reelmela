# ReelMela — Project Overview
**Tagline:** Don't post alone. Post together, go viral together, earn together.
**Version:** MVP v1.0 | **Date:** 24 Nov 2026 | **Founder Location:** Harda, Madhya Pradesh, India

## 1. The Problem
- User goes to event (college fest, garba, concert, wedding, marathon), shoots a reel, posts on Instagram.
- Result: 150-300 views. No viral. No money. No aftermovie.
- 500 other people filmed the same event, all posting alone, all flopping.
- After event, user tries to find a person they saw at event via hashtags — never finds them.

## 2. The Solution — ReelMela
One platform for one event:
1. Join Event -> Upload 15-30 sec clip -> AI stitches best clips
2. Platform posts ONE Collab Reel (with all creators tagged) + ONE Free Aftermovie
3. If viral, earnings split by watch-time contribution
4. PRO users get guaranteed spot in Aftermovie + HD download
5. Mela Meet: Opt-in matching with people from SAME event. Mutual like reveals Instagram ID.

## 3. Core Pillars
1. **Events:** Public + Private events, QR join, live counter
2. **Reels Feed (In-App):** Vertical feed of Collab Reels + Aftermovies + Best Clips. Filters: For You | Near You | Collab Reels | Aftermovies | Meet
3. **Aftermovie Engine:** Coded video pipeline (Claude + Python + MoviePy/FFmpeg) — no $99/mo VidRush needed
4. **Wallet & Revenue Split:** Transparent split by clip watch-time
5. **Mela Meet:** Event-based, consent-first matching. 18+ only.
6. **PRO:** ₹99/event or ₹199/month

## 4. Target User
- Primary: 16-28 yr, college students, Tier 2/3 India (Harda, Indore, Bhopal, Ujjain)
- Secondary: Event organizers, local cafes/brands, wedding planners
- Tertiary: Creators with 500-10k followers who can't go viral alone

## 5. Success Metric for MVP
- 1 event, 30 uploads, 1 collab reel > 50k views, 1 aftermovie delivered, 5 PRO sales
- If that happens, idea is validated.

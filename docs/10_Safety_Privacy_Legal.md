# ReelMela — Safety, Privacy & Legal (CRITICAL)

## 1. Meet Safety (Dating)
- 18+ ONLY. Age gate at signup, ID check in v2 (Aadhaar / College ID optional)
- Meet is OPT-IN. Default OFF. User can turn off anytime, profile disappears.
- NO Instagram ID, phone, live location before mutual match. Only after BOTH like -> reveal IG handle.
- No screenshot of IG ID? Show warning: "Don't share personal info outside app"
- Block + Report on every profile. 2 reports -> auto-hide + admin review.
- Women can choose: "Show me only to verified users" / "Hide my profile from event"
- No location tracking. Only city-level, event-level, never live GPS.
- Safety tips screen before first Meet use.

## 2. Video & Content Safety
- Uploader confirms: "I filmed this, I have permission"
- No hate, no sexual, no violence. Auto-flag via Firebase + manual review.
- Private events: Clips visible only to event members, not public feed.
- Right to delete: User can delete own clip anytime, removed from future aftermovies.
- No filming in bathrooms / private areas. Organizer guidelines.

## 3. Privacy & Data (India DPDP Act 2023)
- Collect only: Name, Photo, City, Age, IG handle (optional), Clips
- Never sell data. Never share phone number.
- Privacy Policy + Terms in app, in Hindi + English.
- Data deletion: User can request delete account, all clips deleted in 30 days.
- Storage in India region (Firebase asia-south1 Mumbai) where possible.

## 4. Payments & Legal
- Use Razorpay for PRO + Organizer fee. No cash handling.
- Earnings: Show TDS note if >₹10k/year (consult CA). Keep transaction logs.
- Business: Register as Sole Proprietorship / LLP before taking organizer money. Open current account.
- Copyright: Music only royalty-free (Pixabay, YouTube Audio Library). No Bollywood songs in Aftermovie without license.
- Instagram: Don't scrape IG. User types own handle. Collab posting via official Meta API or manual posting with permission.

## 5. Moderation Workflow
- Clip upload -> Auto-check duration/size -> Admin queue -> Approve/Reject in <2 hrs
- Report -> Hide immediately if 3 reports -> Admin reviews in 24 hrs
